# Grids → OP-1 port

Mutable Instruments Grids' pattern generator for the OP-1's Blackfin BF524, to become the OP-1's drum sequencer. It's bit-exact with upstream, uses integer code only, and has an OP-1 layer that turns the sequencer clock (96 ticks per beat) into drum-key note events.

- What's ported, how it's verified, the CPU and size costs, and the OP-1 integration design: `docs/grids-port.md`.
- The OP-1 sequencer interface it plugs into: `docs/sequencer-interface.md`.

## Layout

| Path | What |
|---|---|
| `src/pattern_generator.*` | The port of upstream `grids/pattern_generator.*` (namespace `op1grids`). It's an instance with its own LFSR, and has no statics, PROGMEM or EEPROM. Arithmetic unchanged |
| `src/grids_tables.*` | The 25 drum-map nodes and the Euclidean table as plain const arrays, plus the 5×5 node map as indices. Generated by `scripts/gen_tables.py` |
| `src/drum_sequencer.*` | The OP-1 layer:<ul><li>host `Tick(t)` (t = tick mod 48) → Grids 32nd steps;</li><li>swing (as Grids' `clock.Wrap`), 16th/32nd resolution;</li><li>part → drum key mapping, accents (velocity or alternate key), gate lengths;</li><li>note on/off events, AllNotesOff.</li></ul> |
| `shim/` | Host-only stand-ins for `avrlib/*`, `avr/*` and `grids/hardware_config.h`, so upstream's `pattern_generator.cc` and `resources.cc` compile unchanged. avrlib is not checked out in `mutableinstruments/`. The shims match pichenettes/avril's `random.h`/`random.cc` (LFSR `0xb400`, seed `0x21`) and the C versions of `op.h`'s `U8Mix` / `U8U8MulShift8` |
| `tests/compare.cc` | The port against upstream (~15 M checked calls) and the OP-1 layer against upstream driven step by step |
| `tests/bench.cc` | Cycles per tick on the Blackfin simulator, and an event checksum that must equal the host's |
| `harness/cycles.h` | Cycle counter (copy of `ports/rings/harness/cycles.h`) |

## Prerequisite

`mutableinstruments/grids/` (gitignored) at the repo root. Only `make compare` / `make patterns` / `make tables` need it; `src/` doesn't.

## Build (WSL, from this directory)

```
make compare    # bit-exact check vs upstream + OP-1 layer checks -> out/compare.txt
make patterns   # ASCII patterns for a few map points -> out/patterns.txt
make sim        # Blackfin simulator: checksum == host, cycles per tick -> out/sim.txt
make size       # freestanding Blackfin objects: sizes, no ctors, no helper calls -> out/size.txt
make tables     # regenerate src/grids_tables.cc
```
