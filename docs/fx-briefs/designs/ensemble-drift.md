## What it is

Each voice a vertical white **string**, the L lane above (y 30..70) and the R lane below (y 86..126) on
dim guides over x 44..236, swaying about a dim **home mark** (x 80, 140, 200) with the LFO; green
**depth ticks** either side of each mark show how far it can drift. At the right the blue **sweep dial**
(r 10 at (268,66), its dot circling at the rate) with the **rate bar** under it (x 252..284, y 92); the
blue **input-gain gauge** at x 16 (rows 28..124, 0 dB at y 76); the orange **mix gauge** at x 304. Mono
positions hide the R lane. Blue pressed: a bracket round the gain gauge and a blue dB readout top left.

## Ids and mappings

| id | kind | value → |
|---|---|---|
| `vL1..vL3`, `vR1..vR3` | count set per lane, translate | voices: n = 1 + round(2v) shown (R only on the master); per frame `translate(depth x 28 px x sin(phi + i x 2pi/3 (+ pi for R)), 0)` |
| `hL1..hL3`, `hR1..hR3` | the same count set, ScaleX about the mark | depth: the mark-and-ticks group scaled by depth (min 0.02), the mark stays, the ticks reach +-28 x depth |
| `laneR` | group | shown on the master only |
| `sweep` | group, translate | per frame round the dial: `translate(10 sin phi, 10 - 10 cos phi)`, phi advancing at the rate (0.05..8 Hz, log) |
| `rbar` | rect, ScaleX about 252 | rate: u = rate / 32767 (min 0.02) |
| `gbar` | rect, matrix | gain word 5: scaled -1..1 about y 76 |
| `gzero` | static | the 0 dB mark |
| `gbox`, `gs0..1`, `gd0..6`, `gdot`, `gt0..9` | shown on page 2 | the bracket and the readout: tenths = (w x 120 + 16383) / 32767 - 60 |
| `mbar` | rect, matrix | mix: scaled about its foot (y 124) |

Static group `static`: the L lane's guide, the dial's circle, the rate track. The gauges' frames are
static too.

## Gain in the plugin

The ensemble core has no gain of its own and nothing nonlinear, so the plugin scales the decimated
input in place before the core (`Gain()` in `ensemble_knl.cc`, saturating): the wet path only; the dry
side of the mix is the input as it came. Heard as the wet voices louder or softer against the dry.
