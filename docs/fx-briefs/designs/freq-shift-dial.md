## Control map (changed)

Blue press → page 2 = the **input gain** (word 5), as on every module. Green press → page 2 = the
**mode** (word 6, one click flips shifter / ring mod; was blue's word 5 in cs_shift). The mode marks are
green for that reason.

## What it is

A bipolar **arc** spanning the width between the gauges: centre (160,124), r 100, 78 degrees each way
from the top (0 Hz) to the ends (-2 kHz left, +2 kHz right), with a 0 Hz mark, end ticks and a hub.
Blue **needles** from the hub: one on a synth or drum; on the master two, L at shift + spread/3 and R at
shift - spread/3, with a white **spread arc** between them under the rim; in ring mode both needles,
mirrored about the top at the carrier's angle. Green **feedback arcs** inside, a count set, sweeping
right from the top for a shift up, mirrored for down, centred on the top in ring mode. The **mode
marks** top left (x 48, y 14): an arrow (shifter) and a ring (ring mod), the active one green. The blue
**input-gain gauge** at x 16 (rows 28..124, 0 dB at y 76), the orange **mix gauge** at x 304.

## Ids and mappings

| id | kind | value → |
|---|---|---|
| `ndlL`, `ndlR` | lines, rotated about (160,124) | shift f = (v - 16384) x 2 (-1..1); L: f + spread/3, R: f - spread/3 (spread 0 off the master); ring: the carriers, L at +(abs f + spread/3), R at -(abs f - spread/3), mirrored about the top. Turn = 78 deg x value. `ndlR` hidden on a synth or drum in shifter mode |
| `sp1..sp7` | variant set, rotated | spread: k = round(7 x sp) (every position, both modes), `spk` turned by 78 deg x f (x abs f in ring mode); on the master it spans the needles, which part only there |
| `mbox` | rect | shown while green is on page 2 (the mode): a bracket round the mode marks |
| `rp1..rp4` | arcs at r 20, matrix + line colour | the sound's ripples: born at the hub when the input level (the render's block peak, decaying) is up, scaled out to the rim over 0.8 s (`matrix(s,0,0,s,160(1-s),124(1-s))`, s 1..5) and faded from `palmid` to black, at most one every fifth of a journey |
| `fu1..fu4` | count set | feedback: round(4 x fb) arcs in shifter mode; for f < 0 each mirrored about the hub (`matrix(-1,0,0,1,320,0)`) |
| `fr1..fr4` | count set | feedback in ring mode |
| `modea1`, `modea2`, `moder` | line colours | the mode: green (`palgreen`) / dim (`palmid`), read from the file at init |
| `gbar` | rect, matrix | gain word 5: scaled -1..1 about y 76 |
| `gzero` | static | the 0 dB mark |
| `gbox`, `gs0..1`, `gd0..6`, `gdot`, `gt0..9` | shown on page 2 | the bracket and the readout: tenths = (w x 120 + 16383) / 32767 - 60 |
| `mbar` | rect, matrix | mix: scaled about its foot (y 124) |

Static group `static`: the arc, the 0 Hz mark, the end ticks, the hub. The gauges' frames are static too.

## The rotation

The needles and the spread arc turn by a full affine matrix (`RotateAbout` in `shift_knl.cc`:
`matrix(cos, sin, -sin, cos, e, f)` about the hub, Q10) through the renderer's 3 x 3 transform. Every
earlier screen used only scale and translate (the diagonal and the last row); this is the first use of
the b and c terms. If the device ignores them (Test 60), the fallback is pre-drawn needle variants.

## Gain in the core

`ShiftParams::gain` (Q14, default 16384) scales the analytic signal after the Hilbert, both halves,
saturating, before the channels' rotation and feedback: the wet path only, the dry side of the mix is
the input as it came. In ring mode it drives the modulator harder. `ports/fx/tests/test_shift.cc`
passes unchanged on the host.
