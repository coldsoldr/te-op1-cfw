## What it is

The signal path as a circuit, left to right on the rail y 78: the input jack, the **input gain as a
potentiometer** (a dim resistor x 30-62 with a blue wiper arrow above it), the node, the **clipper**
(two anti-parallel blue diodes to ground, x 52 and 80, y 88-116, ground at y 122), the **triode** (a
white circle r 34 at x 152: plate bar with its lead up and over to the right, dashed grid on the rail,
cathode bracket with its lead to ground, the filament hanging under the cathode over a glow), the
**tilt EQ** as its S-shaped response about a pivot at x 248, the output arrow, and the orange mix
gauge at the far right (x 304, as the bitcrusher's). No category dots: a plugin is its own entry.

## Ids and mappings

| id | kind | value → |
|---|---|---|
| `wiper` | group, translate | gain word 5: `translate((w - 16384) x 13 / 16384 px, 0)`, -6 dB at the left end of the resistor, +6 dB at the right |
| `clip1..clip7` | variant set | drive: k = round(7 x drive), `clipk` shown (none at 0): the diodes' triangles filled from the tip by k/7, conduction rays beside them from 5, a second pair at 7 |
| `dio` / `diodim` | groups | the diodes' outlines: `dio` (blue) while blue is on page 1, `diodim` (dim) on page 2 |
| `gs0..gs1`, `gd0..gd6`, `gdot`, `gt0..gt9`, `grule` | one of each shown | the dB readout above the pot while blue is on page 2: tenths = (w x 120 + 16383) / 32767 - 60, sign, digit, point, tenth; blue, stroke font `common/knl_glyphs.py` |
| `fil` | line colour | bias: `paldim` #38354D (cold) → `palwhite` #DED7FF |
| `glow` | fill colour | bias: `palblack` #010101 → `palglow` #7A6E8C |
| `tilt` | polyline, matrix | tone t: `matrix(1,0,0,d,0,78(1-d))`, d = 2t - 1 (clamped to ±4/1024 so the flat centre is a line) |
| `mbar` | rect, matrix | mix: scaled about its foot (y 124), as the bitcrusher's gauge |
| `palette` | hidden lines | the colours the screen blends between, read at init |

Static group `static`: the wires, jack, resistor, node, grounds, envelope, plate, grid, cathode,
pivot, output arrow, gauge frame.

## Gain in the core

`DriveParams::gain` (Q14, default 16384) scales the clipper's gain K before the exponent split and
divides the interpolator's b/K so the bias point stays put; the auto-level table is indexed by the
drive knob alone, so the gain is heard as more or less clipping, not a level change, and the dry side
of the mix never sees it. K is clamped under 2^7 (the exponent table), so above about +30 dB of drive
the top of the gain's range adds nothing. `ports/fx/tests/test_drive.cc` passes unchanged on the host
(the default gain).
